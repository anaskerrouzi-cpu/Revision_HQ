REVISION HQ — YEAR 11
Open index.html in a browser. Features include a five-day timetable, 15 tickable study blocks, progress and streak tracking, an editable mock countdown, daily reminder time, and revision methods for the selected subjects.

REMINDERS
Set a reminder time and press Enable reminders. If prompted, allow browser notifications. The app must be open in a browser to check the time; reminders are not guaranteed when the page/browser is closed. This is a limitation of a simple static website and not a dependable alarm-clock replacement.

Progress saves in local browser storage on that device. It does not sync between devices.

To publish online: upload index.html to a GitHub repository and enable GitHub Pages in Settings > Pages. Open the published page on a phone and use Add to Home Screen if available.

The mock date is unset because it has not been confirmed. Exam boards are unknown, so use teacher guidance and class notes. Science blocks should be adjusted to the school's Combined Science course.
